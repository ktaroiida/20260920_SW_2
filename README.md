# SAN-IN HIDDEN JAPAN

「まだ知らない山陰が、届く。」
鳥取・島根を中心とした山陰地方に眠る、未発掘の伝統・文化・地域資源を再編集し、全国・世界へ届けるD2CブランドECのプロトタイプです。

## プロジェクトの目的

このサイトは、A/Bテスト（シークレットボックス訴求 vs カタログ訴求）の結果を踏まえ、**両方の体験を統合した本格的なブランドECサイト**として構築されています。
単なる「お土産EC」ではなく、商品が持つ「物語」や「背景」を深く伝えることで、ユーザーに新しい発見と情緒的価値を提供することを目的としています。

## ページ構成

本プロトタイプは以下の複数ページで構成され、相互に回遊可能です。

### 1. メインページ
- `index.html` : TOPページ（2つの出会い方、3つの物語、各カテゴリへのハブ）
- `about.html` : ブランドの思想と背景
- `shop.html` : 商品カテゴリ一覧

### 2. 体験・購入ページ（CATEGORIES）
- `secret-box.html` : SECRET BOX（都度購入型のおまかせギフト箱）
- `category-shiba.html` : 山陰柴犬グッズ
- `category-craft.html` : 伝統工芸品
- `category-food.html` : 食品・特産品

### 3. ブランドストーリー（STORIES）
商品の背景にある歴史や文化を深く知るための読み物ページです。
- `stories.html` : ストーリー一覧
- `story-shibainu.html` : 山陰柴犬の物語（消えかけた犬を、地域で守る）
- `story-ushinotoyaki.html` : 牛ノ戸焼の物語（100年前から続く、地域の商品づくり）
- `story-shiroika.html` : 白いかの物語（夏の夜、海に灯りが浮かぶ）

### 4. 商品詳細デモ（PRODUCTS）
代表的な商品の詳細ページプロトタイプです。
- `product-shiba-plush.html`
- `product-craft-washi.html`
- `product-food-shiroika.html`

### 5. ビジネス情報
- `vision.html` : 今後の事業展開の7ステップ
- `investors.html` : 投資家・協業先向けの事業コンセプト

## デザイン方針

- **Quiet & Premium**: 深い藍色、夜のグレー、生成り、アクセントのゴールドを基調とし、余白を活かした静かで上質な和のトーン。
- **Story-driven**: 「TOP（興味）→ STORY（物語を知る）→ SHOP（商品を見る）」という段階的なユーザー体験の設計。
